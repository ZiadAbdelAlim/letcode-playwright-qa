## Critical Anti-Patterns (do NOT repeat these)
- **Don't conflate `.click({ trial: true })` with "click was rejected"** — `trial:true` only does reachability checks; for "disabled rejects click" assertions use a real `.click({ timeout })` and assert `.rejects.toThrow()`.
- **Don't assume Angular Material `mat-sort-header` updates `aria-sort`** — letcode's table uses `jsaction` styling that visually sorts rows but never updates ARIA. Assert against row data, not `aria-sort`.
- **Don't rely on `Locator.dragTo()` for Angular CDK drop zones in Chromium** — use multi-step `page.mouse.move/down/move/up` with at least 20 steps and a small initial bump.
